# CSS Mini Project - Sidebar Menu

## About the Project

This is a mini web development project created while practicing
HTML and CSS.

The project features a sidebar navigation menu with a hamburger
button that opens and closes the sidebar using a CSS checkbox
technique.

## Features

- Sidebar navigation menu
- Open and close functionality
- CSS hover effects
- Font Awesome icons
- Google Fonts integration
- Background image
- Social media icons
- Smooth sidebar transition

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
